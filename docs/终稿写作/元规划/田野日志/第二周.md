# 田野日志\_南山区施工安全监督站\_第二周（20260209至20260213）





## 20260209



我工位的左手边是六个篮子，分别对应1-5组和综合督查组，今天上午大约有5个人来放材料，保守估计每天至少有10份要放到这些篮子里。

下午，有个人到窗口问“住建与建筑是不是一起的”，解释道“我们有诉求”，说给信访办打过电话，让他找住建局，导航导到这里。慧姐告诉他找错了，并补充说他可能进不去位于区政府的住建局。那个人道谢走后，许哥调侃这个时候有诉求一般都是欠薪的。

今天下午，文书工作出人意料地又让我晕头转向。由于我在上一轮的文书工作中介入得不够深和全面，并犯了一个小错误，我又积累下相当多文书修改任务。所幸，立案申报操作不要求手续完整的视听资料和笔录，我可以抓住执法对象在责改送达与回复时来到单位的契机让他们重新签署文书。

由于需要整合深圳湾滨海商务中心2025年10.18事故相关文书，为撰拟暂扣安证请示做准备，我翻查了南山区“智能监管”系统和内部台账。有意思的是，我并没有在系统里检索到与这个事故相关的责令停工通知书，这可能是因为牵涉到亡人事故的缘故。实际上，可于系统上查询到的2025年开出的责停文书在文号上不过达到一千出头，而为这件事故开出的文书是深南住建安停\[2025]2008-2010号。粗略扫视2025年台账的红牌区可以发现，开出的责改或责停文书在文号上通常是0或1打头的四位数，一项2打头的五位数责改文号对应无证施工的警示内容，一项6打头的五位数文号对应典型的高坠1人亡人事故。我直接关心的10.18事故的责停文书文号也很特别，是2打头的四位数。这个事故尽管亡人，但是并不是典型的安全生产事故——一名收材料的非施工人员搭乘叉车意外与一辆三轮车相撞窒息死亡。



## 20260210



一个监管员走进窗口请许哥办一个跟复工有关的手续，许哥开玩笑说着急今天办，不着急年后办，这个监管员用相对严厉说“我们是管安全的，不是管质量的，要快，尽早把锅甩出去”，还提到一位署长不慎被降职的经历。

会敏姐多次找我确认那个“一事两罚”的案子中的两个涉事主体所分别负责的施工模块是不是存在矛盾，因为这两个主体负责的都是幕墙施工。卢工澄清说如果一个模块工程量很大的话，分成几份包出去也是合理的。

上午那个监管员下午来到窗口闲聊，是他手下管过的项目都还可以，没有说项目结束了就不理他的，说“他们是知道我的为人的”。他还说他当时手上一百多个项目的时候一个项目只让3个人进，管理得可高效了，无人机检查他们主动就回复我。
